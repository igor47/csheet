# Reference Documents

The D&D System Reference Documents, as the original PDFs and as Markdown.

The Markdown files are vendored from
[your5e/5e-srd-markdown](https://github.com/your5e/5e-srd-markdown), which
converted the PDFs and lists its conversion notes in its README. To update
them, bump `UPSTREAM_SHA` in `utils/sync-srd.ts` and run `mise run srd:sync`.
